About this version

This comparison version can use OpenAI to interpret the user's search phrase, correct obvious typos, and return structured intent. The app still gets all energy observations from the U.S. Energy Information Administration API.

If OpenAI is not configured or fails, the backend falls back to rule-based interpretation.
