## Reproduce

Use a separate checkout at the exact base. Set `BUNDLE` to the extracted ZIP directory. Dependencies require registry access unless the locked packages are already cached; the tests/build below use no credentials. Do not apply archived rejected-prototype files.

```sh
git clone --no-checkout https://github.com/ae47250/EIAapp.git EIAapp-review
cd EIAapp-review
git checkout --detach {{base}}
git apply --check "$BUNDLE/diff/complete-changes.patch"
git apply "$BUNDLE/diff/complete-changes.patch"
npm ci --ignore-scripts --no-audit --no-fund
OPENAI_API_KEY= EIA_API_KEY= node --test --test-reporter=tap tests/eia-scope-independent.test.js tests/eia-scope-metadata-labels.test.js
OPENAI_API_KEY= EIA_API_KEY= node --test --test-reporter=tap

git diff --cached --check
```
